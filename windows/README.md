# Сборка и запуск под Windows (AvitoParser.exe)

Здесь лежит всё для превращения проекта в один исполняемый файл,
который запускается двойным кликом на любой Windows 10/11 x64
**без установленного Python**.

## Что внутри

| Файл | Назначение |
|---|---|
| `avito_parser.spec` | Спецификация PyInstaller (шаблоны, миграции, скрытые импорты) |
| `build_exe.bat` | Сборка «в один клик» на Windows |
| `requirements-build.txt` | Зависимости только для сборки (pyinstaller, waitress, whitenoise) |
| `../run_app.py` | Точка входа: миграции → веб-сервер → браузер |
| `../.github/workflows/build-windows-exe.yml` | Сборка .exe в GitHub Actions |

## Важно: Chrome нужен на машине пользователя

Парсер работает через Selenium и **управляет настоящим Chrome**.
Сам браузер в .exe не упакован (это ~200 МБ и лицензионные нюансы),
поэтому на компьютере должен быть установлен **Google Chrome**.
Драйвер (`chromedriver`) качать не нужно — Selenium Manager, входящий в
сборку, подберёт и скачает его автоматически при первом парсинге
(нужен доступ в интернет).

## Вариант A. Собрать самому на Windows

Требуется Python 3.10–3.12 с python.org (галочка «Add python.exe to PATH»).

```bat
git clone https://github.com/Krd2024/Avito-selenium-parser.git
cd Avito-selenium-parser
windows\build_exe.bat
```

Результат: `dist\AvitoParser.exe` (~40–60 МБ).

## Вариант B. Собрать в GitHub Actions (Windows-машина не нужна)

1. Вкладка **Actions** → workflow **Build Windows exe** → **Run workflow**.
2. По окончании скачать артефакт `AvitoParser-windows`.

Либо запушить тег `vX.Y.Z` — .exe автоматически приложится к релизу.

## Запуск

1. Положить `AvitoParser.exe` в отдельную папку (например `C:\AvitoParser`).
2. Двойной клик. Откроется окно консоли и браузер на `http://127.0.0.1:8000`.
3. Консоль закрывать нельзя — это и есть сервер. Остановка: `Ctrl+C`
   или закрытие окна.

При первом запуске рядом с .exe создаётся `db.sqlite3` — база с запросами
и результатами. Она сохраняется между запусками; чтобы начать с нуля,
удалите файл.

### Аргументы командной строки

```bat
AvitoParser.exe --port 8100      :: другой порт
AvitoParser.exe --no-browser     :: не открывать браузер
AvitoParser.exe --host 0.0.0.0   :: доступ с других машин в сети
```

Если порт 8000 занят, приложение само возьмёт следующий свободный.

### Настройки (необязательно)

Рядом с .exe можно положить файл `.env` (образец — `.env.example` в корне
репозитория), например:

```ini
PARSE_INTERVAL_MINUTES=60
PROXY_ROTATION=round_robin
PROXY_LIST=185.204.0.1:8000,185.204.0.2:8000:user:pass
```

Список прокси можно вынести в `proxies.txt` рядом с .exe
(формат — в `proxies.txt.example`).

По умолчанию используется SQLite. Чтобы работать с MySQL, укажите в `.env`
`DB_ENGINE=mysql` и параметры подключения — драйвер PyMySQL уже в сборке.

Если .exe лежит в защищённой от записи папке (`Program Files`), укажите
каталог для данных переменной окружения `AVITO_DATA_DIR`.

## Возможные проблемы

| Симптом | Причина и решение |
|---|---|
| Антивирус / SmartScreen ругается на .exe | Обычная реакция на неподписанные PyInstaller-сборки. «Подробнее» → «Выполнить в любом случае» либо подписать сборку сертификатом |
| Окно мигнуло и закрылось | Запустите из `cmd`, чтобы увидеть текст ошибки |
| `Unable to obtain driver for chrome` | Не установлен Google Chrome либо нет доступа в интернет для скачивания драйвера |
| Авито показывает капчу | Нужны прокси — см. раздел про `proxies.txt` и `ANTI_DETECT.md` |
| Порт занят | Приложение возьмёт следующий свободный; либо задайте `--port` |
